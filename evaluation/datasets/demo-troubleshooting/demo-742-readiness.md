# Учебный стенд: DEMO-TS-742 — проверка доступности Demo Gateway

Это синтетическая демонстрационная статья. Demo Gateway, код DEMO-TS-742 и порт 18443 вымышлены; материал не описывает корпоративную систему.

## Симптом и граница проверки

DEMO-TS-742 означает, что клиент учебного стенда не получил ответ readiness endpoint. Статья помогает собрать наблюдения. Она не доказывает, что сервис доступен сейчас: для этого нужны результаты выполнения на конкретном стенде.

## Диагностика

Сначала прочитайте состояние службы. Затем проверьте readiness endpoint. После этого прочитайте последние 40 записей журнала. Сохраните HTTP status, время проверки и строки с DEMO-TS-742.

Точный исходный блок команд:

```bash
systemctl status demo-gateway.service --no-pager
curl --fail --show-error --silent \
  --max-time 3 \
  http://127.0.0.1:18443/ready
journalctl -u demo-gateway.service -n 40 --no-pager
```

Ожидаемый положительный результат HTTP проверки — статус 200 и тело `ready`. Timeout не определяет первопричину: нужно отдельно проверить службу, endpoint и журнал. В статье нет команды перезапуска и нет инструкции удаления данных.
