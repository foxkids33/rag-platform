# Confluence RAG — чистая установка

Этот пакет создаёт собственную пустую установку. Прежние рабочие области,
документы, диалоги и демонстрационные материалы в него не входят.
Прямой доступ к Confluence включён; отдельный коннектор не требуется, если
сервер RAG может обращаться к Confluence и сервисам моделей.

Пакет предназначен для локальной проверки и пилота одной команды с общим
разрешённым корпусом. Для работы нужны внешний Confluence, модель ответов
с OpenAI-совместимым API и embeddings с протоколом `POST /embed`.
Модели, их веса и доступ к корпоративным системам не поставляются.

Из корня распакованного архива:

```bash
./scripts/deploy/setup-clean-env.sh --output ./confluence-clean.env --mode pilot
./scripts/deploy/compose-clean.sh --env-file ./confluence-clean.env build
```

Заполните созданный файл в редакторе: адреса и имена моделей, размерность
embeddings, параметры Confluence, серверный токен и список разрешённых
пространств. Файл содержит секреты и имеет права `600`.

```bash
./scripts/deploy/compose-clean.sh --env-file ./confluence-clean.env config
./scripts/deploy/compose-clean.sh --env-file ./confluence-clean.env --allow-local-pilot up
```

Откройте `http://127.0.0.1:18573`, создайте рабочую область и выберите страницы
Confluence. Индексация запускается после явного импорта. Остановка с сохранением
данных:

```bash
./scripts/deploy/compose-clean.sh --env-file ./confluence-clean.env down
```

Полные настройки, OIDC, сетевые требования и ограничения — в
[инструкции](docs/confluence-clean-deployment.md).

Персональные права страниц Confluence не переносятся в RAG автоматически.
Общий корпус должен быть разрешён всей целевой команде. Для промышленного
использования необходимы проверка настоящих интеграций, OIDC и выбор
поддерживаемого S3-хранилища: используемый в пилоте MinIO Community архивирован
его разработчиком. PDF/OCR в лёгкий профиль не входят.

`CLEAN_SOURCE_MANIFEST.json` содержит контрольные суммы файлов архива.
Сборка скачивает зависимости и закреплённый официальный исходный код MinIO;
готовые образы RAG и GPU-модели в архив не включены.
