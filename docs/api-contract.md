# REST API и спецификация

Swagger доступен по `/api/docs`, машинная OpenAPI-спецификация — по
`/api/openapi.json`, ReDoc — по `/api/redoc`. Все адреса проходят через
существующий web/Nginx и не требуют внешнего backend-порта.

Спецификация генерируется FastAPI из установленных маршрутов и Pydantic-моделей,
а не поддерживается отдельным вручную составленным списком. Бизнес-маршруты
используют префикс `/api/v1`; это собственный workspace API платформы,
не OpenAI-compatible `/v1/chat/completions`.

## Основные контракты

- `POST /api/v1/workspaces/{workspace_id}/search` принимает JSON с `query`,
  режимом поиска и лимитом; возвращает JSON с результатами и метаданными.
- `POST /api/v1/workspaces/{workspace_id}/answer` принимает `AnswerRequest`
  с `question`; возвращает `AnswerResponse` с ответом, источниками и аудитом.
- `POST /api/v1/workspaces/{workspace_id}/answer/stream` принимает тот же JSON,
  но возвращает `text/event-stream`. События: `metadata`, `token`, `done`
  либо `error` при обработанном сбое генерации. В `data` находится JSON.
  После начала потока ошибка передаётся событием, а не сменой HTTP 200 на 502.
  Текст буферизуется до проверки цитат и блоков кода; это не обещание отдачи
  каждого токена модели сразу после генерации. Нативный браузерный EventSource
  не поддерживает этот POST-контракт; нужен streaming fetch или совместимый клиент.
- Загрузка документов использует `multipart/form-data` с обязательным `file`
  и возвращает JSON документа с HTTP 201. Важные ошибки загрузки описаны
  отдельно: пустой файл, отсутствие доступа, конфликт, размер, расширение
  и недоступность хранилища. Валидация полей FastAPI использует HTTP 422.
- `GET /api/v1/connectors/{connector_id}/jobs/next` — long-poll: HTTP 200
  с `ConnectorJobLease` либо HTTP 204 без тела, если работы пока нет.

## Авторизация

`HTTPBearer` означает пользовательский OIDC access token в защищённом режиме.
При `AUTH_ENABLED=false` пользовательский токен не требуется; спецификация
пилота не объявляет его обязательным. Это не режим для открытого Интернета.

`ConnectorBearer` — отдельный машинный credential, выданный при регистрации
коннектора. Он обязателен на машинных маршрутах даже при отключённой
пользовательской авторизации. OIDC access token не заменяет этот credential.
В Swagger их можно задать отдельно через Authorize. Не сохраняйте реальные
токены в исходниках или в публикуемых примерах.

## Проверка соответствия

`tests/test_openapi.py` проверяет публикацию документации через `/api/`,
совпадение method/path спецификации со всеми зарегистрированными бизнес-
маршрутами, уникальность operationId, формат SSE и оба режима авторизации.
`tests/test_openapi_routes.py` проверяет lease/204 и схемы multipart/error upload.

Это проверка контракта, не выполнение всех бизнес-операций в production и не
нагрузочное испытание. Автоматически отображаются модели успешных ответов и
валидация 422; перечни всех возможных инфраструктурных ошибок для остальных
операций пока не исчерпывающие. Swagger Try it out реально обращается к API:
не запускать изменяющие операции без намерения создать или изменить данные.
