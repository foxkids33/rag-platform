# Учебный стенд: DEMO-TS-743 — точные параметры Demo Gateway

Это синтетическая демонстрационная статья. Demo Gateway и DEMO-TS-743 вымышлены; материал не описывает корпоративную систему.

## Когда использовать

DEMO-TS-743 в учебном стенде обозначает несовпадение параметров клиента и readiness endpoint. В этом примере readiness использует HTTP, порт 18443 и путь `/ready`. Значения применимы только к вымышленному учебному стенду.

## Исходный фрагмент конфигурации

Для сравнения с ответом помощника ниже приведён полный блок. Отступы, протокол, порт и время ожидания являются частью исходного фрагмента.

```yaml
demo_gateway:
  readiness:
    scheme: http
    host: 127.0.0.1
    port: 18443
    path: /ready
    timeout_seconds: 3
  retry:
    max_attempts: 2
    delay_seconds: 5
```

Сравните параметры с фактической конфигурацией учебного стенда. Значения `scheme: https`, `port: 8443` и `timeout_seconds: 30` не совпадают с этим исходным фрагментом. Статья не предписывает автоматически менять конфигурацию.
