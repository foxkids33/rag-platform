# Проверки удобства и регрессий UI

`scripts/ui/chat-navigation.test.mjs` запускает Vite на свободном локальном порту
и проверяет интерфейс настоящим браузером через Playwright. Все обращения к API
подменены тестовыми ответами; сервер, Confluence и рабочие диалоги не изменяются.

Используется уже установленный Playwright. Если он доступен не в обычном пути
разрешения Node, передайте путь к его пакету явно:

```bash
PLAYWRIGHT_MODULE=/absolute/path/to/node_modules/playwright \
PLAYWRIGHT_CHANNEL=chrome \
node scripts/ui/chat-navigation.test.mjs
```

`PLAYWRIGHT_CHANNEL=chrome` использует установленный Google Chrome. Без этой
переменной нужен Chromium, установленный для используемой версии Playwright.
Зависимости frontend должны быть установлены в `apps/web/node_modules`.
MCP для этих тестов не требуется.

Проверяются:

- Создание диалога из Confluence, документов, баз знаний и графа; открытие текущего
  и другого диалога из истории; сохранение раздела при ошибке создания.
- Поиск документов, фильтры по статусу, пустая выдача и показ списка порциями.
- Открытие выбора файлов клавишами Enter и Space.
- Выбор страниц Confluence по ID и ссылке, валидация, удаление из выбора.
- Импорт 11 страниц пакетами 10 + 1, прогресс и сохранение оставшихся страниц
  при ошибке второго пакета. Остановка опроса при уходе из раздела.
- Доступ к workspace/истории и видимость статуса документа на мобильном экране;
  отсутствие горизонтального переполнения Confluence при ширинах 320–1280 px.
- Защита от запоздалых ответов документов/диалогов при смене workspace или
  создании нового диалога; сброс выбора Confluence при смене workspace.
- Отмена устаревших запросов версий и документов при смене базы знаний.

Скриншоты с искусственными данными сохраняются в `.storage/ui-review/`:
`confluence-desktop.png`, `confluence-mobile.png`, `documents-mobile.png`.
Проверки не заменяют серверный end-to-end тест индексации/генерации ответов.
